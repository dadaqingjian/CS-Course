# 计算机科学导论 · CS-Course

本仓库整理赣南师范大学“计算机科学导论”课程的教学课件，供同学们平时学习和考前复习使用。

课程以 **Computer Science: An Overview, 13th Edition** 为主要教材，从数据的表示与处理出发，介绍计算机系统、网络、算法、程序设计及数据组织，帮助同学们建立对计算机科学的整体认识。

## 教材与学习内容

**教材作者：** J. Glenn Brookshear、Dennis Brylow  
**出版社：** Pearson  
**教材信息：** [Pearson 官方介绍](https://www.pearson.com/en-us/subject-catalog/p/computer-science-an-overview/P200000003351)

学习本课程时，可以围绕以下问题理解各章之间的联系：

- **数据怎样表示和处理？** 理解二进制、数据编码、存储系统与机器指令。
- **计算机怎样运行和通信？** 理解操作系统如何管理资源，以及网络如何连接设备、传递信息。
- **问题怎样转化为程序？** 理解算法、程序设计语言、软件开发，以及数据结构和数据库的作用。

课件用于梳理概念、展示例子和辅助讲解。学习时请结合教材、课堂说明与练习，理解主要英文术语及其中文含义。

点击上表中的课件链接即可进入对应文件页面。PDF 通常可在 GitHub 中直接预览；PPT 文件可下载后使用 PowerPoint 等支持的软件打开。如果页面没有显示预览，可使用文件页面中的下载按钮保存到本地。

```bash

```

后续在本地仓库目录中执行 `git pull`，即可获取仓库更新。

## 学习建议

1. **课前预习：** 阅读对应章节，记录不熟悉的英文术语和问题。
2. **课堂理解：** 结合图示和具体例子，弄清概念之间的联系及处理过程。
3. **课后练习：** 亲自完成数据表示转换、指令执行跟踪、算法推演和数据结构操作等练习，检查自己能否解释每一步。
4. **阶段复习：** 对容易混淆的概念进行比较，例如进程与程序、因特网与万维网、栈与队列、数据值与地址。
